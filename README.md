# Запуск приложения

**Доступен несколькими способами:**

1. Через docker-compose.yml: `docker-compose up --build`
2. Через docker run:
- Запуск базы данных: `docker run -d --name postgres --network app-network --env-file .env -p 5432:5432 postgres:15`
- Запуск приложения: `docker run -p 8000:8000 --network app-network --env-file .env talrooms`
3. Через запуск main.py

# Создание бронирования

Для создания бронирования комнаты сначала нужно авторизоваться, после чего получить права доступа, как минимум редактора (1), это можно сделать через `docker exec -it postgres psql -U postgres -d TalRooms`, далее через SQL запросы:
1. После регистрации ввести `SELECT * FROM users;` для получения всех пользователей
2. Ищем себя и смотрим какой у Вас ID
3. Далее вводим `UPDATE users SET role=1_ИЛИ_2 WHERE id=ВАШ_ID;`

 Дальше можно бронировать комнату. Если комнат нет - нужно их создать:
 1. Пишем `docker exec -it postgres psql -U postgres -d TalRooms`, чтобы войти в SQL панель
 2. Далее вводим `INSERT INTO rooms (name_room, status, capacity, start_time, end_time) VALUES ('Бриз', 1, 36, '9:00', '12:00');`. Можете выбрать свои значения
 3. Проверяем `SELECT * FROM rooms;` -> в списке должна быть комната, которую Вы добавили

# Редакция бронирований
- Для редактировании бронирования комнаты нужно зайти в Личный кабинет - Раздел "Мои бронирования" - На нужном бронировании нажимаем "Детали" - Редактировать
- Для отмены бронирования заходим в Личный кабинет - Раздел "Мои бронирования" - На нужном бронировании нажимаем "Детали" - Отменить
- Для администратора (2-й уровень доступа) доступно изменение всех забронированных комнат. Можно посмотреть все назначенные бронирования в Личный кабинет - Все бронирования. В этом же меню можно посмотреть все забронированные комнаты как от себя, так и от других сотрудников
